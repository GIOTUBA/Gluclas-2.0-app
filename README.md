# Gluclas-2.0-app-apk
This repository contains **only the compiled Android application (.apk)** for the Gluclas mobile app, developed to support glucose clamp experiments.

⚠️ **Source code is NOT included in this repository.**

## 📱 Download
You can download the latest `.apk` file from the **Releases** section of this repository and install it on an Android device.

## 🔬 About the app
Gluclas is a mobile application designed to assist clinicians and researchers during glucose clamp experiments, providing real-time visualization and support tools.

## 🧾 Source code
The full source code of the application is available in the following repository:

👉 https://github.com/GIOTUBA/Gluclas-2.0-app

## ⚠️ Disclaimer
This application is intended for **research and educational purposes only** and is not certified as a medical device.
